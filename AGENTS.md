# Работа с mafia-ops

- Здесь находятся общий запуск, сквозные проверки и модель релиза платформы.
  Dockerfile и код каждого приложения принадлежат его репозиторию.
- Проверки CI используют точные ревизии из `sources.json`. При обновлении
  приложения проверяйте совместимый набор API, веба и OpenAPI.
- Локальная среда поднимается командой `make dev`. Используйте `make e2e`
  для проверки из браузера и `make down` для остановки с сохранением данных.
- В репозитории допустимы только тестовые учётные данные. Production-секреты,
  дампы, данные игроков и реальные протоколы находятся вне Git.
- Для smoke-тестов через Compose используйте отдельное имя проекта. Удаляйте
  том только у одноразового тестового проекта.
